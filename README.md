# Lógica · 西语第一性原理学习台

面向中文母语者的西语学习网页原型。它不提供孤立单词卡，也不把语法做成“时态清单”，而是以语境输入为入口，把 B2 需要的高频机制压缩成可理解、可调用的底层关系。

直接打开 `index.html` 即可运行；没有构建步骤、没有网络依赖，进度保存在浏览器 `localStorage`。

## 设计总览

### 目标

首要任务不是让学习者完成更多题，而是让学习者在一句真实西语里看见一个关系，并能把这个关系迁移到下一句话。

### 第一性原理图谱

1. **摆放视角**：事件是背景，还是一个封闭落点？这解释未完成过去时与简单过去时的核心差异。
2. **承诺程度**：说话人是在陈述事实，还是推动一个愿望、命令或可能？这解释陈述与虚拟视角的分化。
3. **关系方向**：动作经过谁、落到谁？这解释关系代词为什么不是可有可无的装饰。
4. **信息位置**：共同画面与新信息怎样排列？这解释西语语序如何管理听者注意力。

无法把所有西语现象压缩为一个单一规则；例如词尾变位仍包含历史音变和词类限制。因此本原型采用替代拆解路径：先把语义选择压缩为四个触发器，再让词尾从可理解输入中逐步稳定，而不是要求学习者先背完整范式。

### 克拉申编排

每节固定经过：

1. **输入先行**：先看到西语句子、中文意义和使用场景。
2. **理解层**：展开后解释说话人的视角与因果关系。
3. **调用层**：用一个新场景选择正确的关系，不做高压计分。
4. **最小记忆层**：只留下一个可触发的二分或问题。

内容按自然的理解顺序组织：先能识别背景、愿望、动作落点和信息焦点，再逐步扩展到更复杂的时态、语气和从句。

## UI 规范

- **冷铅灰机壳**：页面底色为 `#E9ECE9`，避免常见的暖米色学习产品。
- **样板纸内容面**：`#FAFBF9` 面板配内凹线条和低幅阴影，借鉴锤子 OS 的拟物层次。
- **暗朱砂状态灯**：`#B84E45` 是唯一主动色，只表示已理解、焦点和可调用状态。
- **重排版与大留白**：单列阅读宽度、明确层级、一个屏幕只承担一个认知动作。
- **不使用**渐变、花哨插画、卡片墙、扣分、连续打卡或强制每日任务。
- 移动端将侧栏收成紧凑导航，保留键盘焦点、对比度和 `prefers-reduced-motion` 支持。

## 实现

- `index.html`：页面结构和四个学习视图。
- `styles.css`：冷灰机壳、样板纸、拟物控件和响应式布局。
- `app.js`：四节内容、理解/调用/回看状态、本地持久化和导航交互。

## 验证清单

- [x] 非背单词：没有独立词表和单词卡，所有西语内容都嵌在语境句中。
- [x] 理解优先：输入句子先于原理解释，原理先于调用。
- [x] 最少记忆：每节只有一个明确触发器，并标注最小记忆层。
- [x] 可调用：每节都有新的场景选择和即时、无惩罚反馈。
- [x] 克拉申对齐：i+1 输入、低焦虑、渐进披露、回看由学习者主动决定。
- [x] 锤子 OS 风格：拟物细节、重排版、大留白、冷静配色、节制动效。
- [x] 可直接运行：双击 `index.html` 或用任意静态服务器打开。
